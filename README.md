# Lybraria

### Aplikasi Pengelolaan Perpustakaan Kampus Berbasis Android

## Deskripsi Project

**Lybraria** merupakan aplikasi mobile berbasis Android yang dirancang untuk membantu pengelolaan operasional dan sirkulasi perpustakaan kampus secara digital.

Aplikasi ini memiliki dua jenis pengguna, yaitu **Admin** dan **Anggota**. Admin berperan sebagai petugas perpustakaan yang dapat mengelola data buku, kategori, anggota, peminjaman, pengembalian, serta denda keterlambatan. Sementara itu, Anggota merupakan mahasiswa terdaftar yang dapat melihat katalog buku, mencari buku, mengajukan peminjaman, dan memantau riwayat serta status peminjaman.

Lybraria dirancang untuk mendukung layanan perpustakaan dalam lingkup satu kampus. Identitas mahasiswa berupa NIM digunakan sebagai dasar verifikasi keanggotaan, sehingga proses peminjaman dapat tercatat dan dipertanggungjawabkan. Pengajuan peminjaman dilakukan melalui aplikasi, sedangkan pengambilan dan pengembalian buku dilakukan secara langsung di perpustakaan kampus.

Aplikasi ini direncanakan dikembangkan menggunakan **Kotlin dan Jetpack Compose** sebagai project akhir mata kuliah Pengembangan Aplikasi Mobile (PAM) 2026.

## Fitur Utama yang Direncanakan

### Admin

- Mengelola data buku.
- Mengelola kategori buku.
- Mengelola data anggota.
- Mengelola peminjaman buku.
- Memproses pengembalian buku.
- Mengelola denda keterlambatan.

### Anggota

- Melihat katalog dan detail buku.
- Mencari buku berdasarkan informasi yang tersedia.
- Mengajukan peminjaman buku.
- Melihat status peminjaman.
- Melihat riwayat peminjaman dan informasi denda.

Seluruh fitur di atas merupakan rencana pengembangan dan belum diimplementasikan.
